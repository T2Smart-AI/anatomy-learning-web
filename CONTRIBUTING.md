# Contributing

Thanks for helping make free anatomy education better! 🎉

## How to help

**No-code ways**
- Report bugs (see issue templates) — include browser, OS, and whether the 3D loaded
- Improve translations (EN/ES/FR/LA structure names live in `src/anatomy-data.js`)
- Fact-check anatomical descriptions against public-domain references
- Suggest structures to add (each entry is one line in `src/anatomy-data.js`)

**Code ways**
- Fork → branch → PR. Keep the style: plain ES modules, no build step, no new runtime deps.
- Good first tasks: keyboard shortcuts, a11y labels, quiz distractor quality, PWA service worker.

## Development setup

```bash
python -m http.server 8000   # or any static server; ES modules need http://
```

Test at desktop (1920×1080) and phone (390×844) widths. The 3D needs network
for `src/models/*.bin.gz`; everything else is bundled.

## Data pipeline

- `src/models/atlas.json` + `sys-<system>.bin.gz` are generated by
  `tools/repack-by-system.mjs` from the raw BodyParts3D chunks. Part indices
  must stay stable — `src/part-map.json` references them by index.
- Never hand-edit `atlas.json`; edit the generator and re-run it.

## Rules

- **Keep attribution.** `src/models/ATTRIBUTION.md` and `NOTICE.md` must stay
  with the model files (CC BY 4.0 requirement).
- No trackers, no ads, no account systems — the app stays free and private.
- Descriptions must remain original writing (1–2 sentences, public-domain sources).
- Don't copy proprietary meshes or text from the commercial app this was rebuilt from.

## Code of conduct

Be kind and inclusive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
